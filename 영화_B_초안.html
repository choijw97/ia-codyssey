🎬 우리들의 영화 티어리스트

가입 없이 8편의 영화를 S~D 등급으로 나누고 친구들과 취향을 비교해 보세요!

💡 사용 방법: 영화를 끌어다 놓거나(드래그), 영화 카드를 누른 뒤 아래 등급 버튼을 골라 옮기세요. 안 본 영화는 대기칸에 그대로 두면 됩니다.
👇 위쪽 두 줄(S·A)에만 몰리지 않게 C·D 칸도 골고루 써 주세요!
S인생작(5점)
A명작(4점)
B무난함(3점)
C아쉬움(2점)
D별로(1점)

🍿 대기칸 (안 본 영화는 여기에 그대로 두세요)

남은 영화: 8편 (제출 시 '안 봄'으로 저장되어 평균 계산에서 제외됩니다)

✅ 내 티어표 제출하고 친구들 결과 보기

⚠️ 안내: 비밀번호는 운영자의 구글 시트에 그대로 기록됩니다. 절대 평소 쓰는 중요한 비밀번호를 쓰지 마시고, 간단한 숫자 4자리(예: 1234)를 입력해 주세요. 같은 이름과 비밀번호로 다시 제출하면 이전 결과를 덮어씁니다.
🎉 님의 티어표가 반영되었습니다! 총 0명의 친구 결과를 비교합니다.
🔥 최고 토론 거리
1. 의견이 가장 갈린 영화

친구들 사이에서 S~D 등급이 가장 넓게 흩어진(표준편차가 가장 큰) 영화입니다.

2. 영화별 요약 (평균 등급 · 분포 · 본 사람 수)

S=5점, A=4점, B=3점, C=2점, D=1점 기준이며, '안 봄'은 평균과 분포 계산에서 제외했습니다.

3. 나와 취향이 가장 비슷한 친구 vs 가장 다른 친구

나와 둘 다 본 영화들의 점수 차이를 비교해 계산했습니다.

4. 친구 개인 결과 찾아보기

이름으로 검색하고 친구 이름을 누르면 전체 티어표가 펼쳐집니다. (비밀번호는 절대 표시되지 않습니다)

🔗 구글 스프레드시트 Apps Script 웹 앱 주소 (URL) 연결

배포할 때는 아래 입력칸에 웹 앱 주소를 넣어 테스트하거나, 이 HTML 파일 안의 DEFAULT_SCRIPT_URL 변수에 주소를 적어 GitHub Pages / Netlify에 올리면 모든 친구들에게 자동 적용됩니다.

📋 1단계: 구글 스프레드시트 연결 코드 설정 (동시 제출 잠금 & 비밀번호 제외 포함)

  1. 새 구글 스프레드시트를 만들고 상단 메뉴에서 [확장 프로그램] → [Apps Script]를 누릅니다.
  2. 기존 코드를 지우고 아래 코드를 붙여넣은 뒤 저장(💾)합니다.
  3. 우측 상단 [배포] → [새 배포]를 누르고, 유형을 [웹 앱]으로 선택합니다.
  4. 다음 사용자 인증 정보로 실행: [나], 액세스 권한이 있는 사용자: [모든 사용자]로 설정하고 배포합니다.
  5. 발급된 웹 앱 URL을 복사해 위 입력칸이나 HTML 코드 상단 DEFAULT_SCRIPT_URL에 넣습니다.

const list = rows.slice(1).filter(r => r[0]).map(r => { const ratings = {}; MOVIES.forEach((m, idx) => { ratings[m] = r[idx + 2] || '안 봄'; }); // r[1](비밀번호)은 의도적으로 제외하여 반환 return { name: String(r[0]), ratings: ratings, updatedAt: String(r[10] || '') }; const name = String(body.name || '').trim(); const pin = String(body.pin || '').trim(); const ratings = body.ratings || {}; if (!name || !/^\d{4}$/.test(pin)) { return jsonResponse({ ok: false, error: '이름과 숫자 4자리 비밀번호를 확인해 주세요.' }); i < data.length; i++) { if (String(data[i][0]).trim() === name) { if (String(data[i][1]).trim() !== pin) { return jsonResponse({ ok: false, error: '이미 등록된 이름이지만 비밀번호가 다릅니다.' }); } targetRow = i + 1; break; } } const now = Utilities.formatDate(new Date(), 'Asia/Seoul', 'yyyy-MM-dd HH:mm'); const rowValues = [name, "'" + pin, ...MOVIES.map(m => ratings[m] || '안 봄'), now]; if (targetRow > 0) { sheet.getRange(targetRow, 1, 1, rowValues.length).setValues([rowValues]); } else { sheet.appendRow(rowValues); } return jsonResponse({ ok: true }); } finally { lock.releaseLock(); } } function jsonResponse(obj) { return ContentService.createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); }
