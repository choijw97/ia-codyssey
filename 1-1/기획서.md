# 영화 티어리스트 웹페이지 기획안

Nov 7, 2026 · @junwoo

## 개요

친구 30명 이상이 가입 없이 링크로 접속해 영화 8편을 S\~D 5단계로 나누고, 구글 스프레드시트에 모인 결과로 서로의 순위를 비교하는 웹페이지를 만든다.

| 항목 | 핵심 결정 |
| --- | --- |
| 누가 쓰나 | 친구 30명 이상, 가입 없이 링크로 접속 |
| 무엇을 하려고 | 친구들과 영화 순위를 비교 |
| 화면과 동작 | S·A·B·C·D 5단계 고정, 끌어다 놓기와 누르고 고르기, 이름과 4자리 비밀번호로 제출 |
| 필요한 자료 | 영화 8편 고정, 제목·개봉 연도 글자 카드, 구글 시트에 한 사람당 한 줄 저장 |
| 완성 기준 | 기능, 비교 화면, 규모와 안전, 화면과 배포 4개 영역의 확인 목록 |

## 1. 누가 쓰나

영화를 좋아하는 친구 30명 이상이 링크를 받아 각자 자기 티어표를 만든다. 만든 사람(운영자)은 페이지를 올리고 구글 시트를 관리한다.

| 구분 | 내용 |
| --- | --- |
| 참여자 | 친구 30명 이상, 휴대폰과 컴퓨터로 접속 |
| 운영자 | 기획자 본인, 호스팅과 구글 시트를 설정하고 관리 |
| 접속 방법 | 단톡방 등에 공유한 링크를 열면 바로 사용, 가입이나 로그인 없음 |
| 페이지 배포 | GitHub Pages나 Netlify 같은 무료 정적 호스팅, 계정은 운영자만 필요 |
| 결과 수집 | 운영자의 구글 스프레드시트에 자동 저장 |

**배포 방식을 이렇게 정한 이유:** Claude 공유 페이지는 [Claude 도움말](https://support.claude.com/en/articles/9547008-share-artifacts)에 따르면 여는 사람 모두 Claude 계정이 필요하다. 참여자 모두가 Claude를 쓰지는 않으므로 제외했다. 결과 코드를 손으로 모으는 방식은 가입 부담은 없지만 비교에 수작업이 들어서, 자동으로 모이면서 친구들에게 가입을 요구하지 않는 구글 시트 방식을 골랐다.

## 2. 무엇을 하려고

목적은 친구들과 영화 순위를 비교하는 것이다. 각자 만든 티어표를 한곳에 모아, 영화별로 의견이 어떻게 갈리는지와 나와 취향이 비슷한 사람을 보여준다.

비교 방식은 "모두의 결과를 함께 보기"를 기본으로 하고, 평균 등급을 보조로 붙인다.

- **평균만 보여주지 않는 이유:** 친구 규모에서는 평균이 의견 차이를 가린다. 한 명이 S, 한 명이 D를 주면 평균은 B가 되어 가장 재미있는 "의견 충돌"이 사라진다.
- **이미지 공유만으로 하지 않는 이유:** 단톡방에 이미지를 올리는 방식은 흔하지만, 30명 이상의 결과를 사람이 번갈아 보며 비교하기는 어렵다.
- **30명 이상이라 요약 중심으로 보여주는 이유:** 모든 티어표를 나란히 놓으면 휴대폰 화면에 들어가지 않는다. 영화별 분포와 의견이 갈린 영화를 먼저 보여주고, 개인 결과는 찾아서 펼쳐 보게 한다.

## 3. 화면과 동작

화면은 "내 티어표 만들기"와 "비교 보기" 두 개이고, 내 결과를 제출해야 비교 보기가 열린다.

### 사용 흐름

1. 링크를 열면 "내 티어표 만들기" 화면이 나온다.
2. S·A·B·C·D 다섯 줄과 아래 대기칸이 있고, 영화 8편은 처음에 모두 대기칸에 있다.
3. 영화를 등급 줄로 옮긴다. 안 본 영화는 대기칸에 그대로 둔다.
4. 이름과 숫자 4자리 비밀번호를 입력하고 제출한다.
5. 제출이 끝나면 "비교 보기" 화면이 열린다.

### 동작 규칙

| 항목 | 결정 |
| --- | --- |
| 등급 | S·A·B·C·D 5단계, 이름과 개수 고정 |
| 옮기는 방법 | 끌어다 놓기, 그리고 영화를 누른 뒤 등급 버튼 고르기 (둘 다 지원) |
| 아래쪽 칸 안내 | "D 칸도 써 주세요" 같은 안내 문구로 위쪽 두 줄에만 몰리지 않게 함 |
| 참여자 구분 | 이름과 숫자 4자리 비밀번호, 평소 쓰는 비밀번호를 쓰지 말라는 안내 표시 |
| 다시 제출 | 같은 이름과 비밀번호면 이전 결과를 덮어씀, 최신 결과만 비교에 반영 |
| 틀린 비밀번호 | 같은 이름에 다른 비밀번호로는 제출이 거절됨 |
| 공개 시점 | 내 결과를 제출하면 바로 다른 사람 결과를 볼 수 있음 |

### 비교 보기 화면 구성

1. **의견이 가장 갈린 영화:** 등급이 가장 넓게 흩어진 영화를 맨 위에 강조한다.
2. **영화별 요약:** 영화마다 평균 등급, 등급 분포(S 몇 명, A 몇 명…), 본 사람 수를 보여준다.
3. **나와 가장 비슷한 사람, 가장 다른 사람:** 내 결과와 다른 사람 결과를 비교해 보여준다.
4. **개인 결과 찾기:** 이름으로 검색해 특정 친구의 티어표를 펼쳐 본다.

평균과 비교 계산에는 S=5점, A=4점, B=3점, C=2점, D=1점을 쓰고, "안 봄"은 계산에서 뺀다.

**공통 화면 조건:** 휴대폰과 컴퓨터, 밝은 화면과 어두운 화면 모두에서 읽기 쉬워야 한다.

## 4. 필요한 자료

필요한 자료는 고정된 영화 8편의 목록과, 결과를 한 사람당 한 줄로 저장하는 구글 스프레드시트 하나다.

### 영화 목록 (8편 고정)

| 영화 | 개봉 연도 |
| --- | --- |
| 기생충 | 2019 |
| 인터스텔라 | 2014 |
| 라라랜드 | 2016 |
| 센과 치히로의 행방불명 | 2001 |
| 어벤져스: 엔드게임 | 2019 |
| 범죄도시 | 2017 |
| 타이타닉 | 1997 |
| 토이 스토리 | 1995 |

- **목록을 고정하는 이유:** 모두가 같은 영화를 평가해야 평균과 분포를 비교할 수 있다.
- **카드 표시:** 제목, 개봉 연도, 영화마다 다른 색을 쓴 글자 카드로 만든다. 포스터는 배급사가 권리를 가진 이미지라 쓰지 않는다.
- **안 본 영화:** 대기칸에 남은 영화는 "안 봄"으로 저장하고 평균과 분포 계산에서 뺀다. 비교 화면에 영화마다 본 사람 수를 함께 표시해, 적은 인원의 평균임을 알 수 있게 한다.

### 구글 시트 저장 구조

한 사람당 한 줄로 저장한다. 영화 칸에는 S, A, B, C, D, 안 봄 중 하나가 들어간다.

| 이름 | 비밀번호 | 기생충 | 인터스텔라 | 라라랜드 | 센과 치히로의 행방불명 | 어벤져스: 엔드게임 | 범죄도시 | 타이타닉 | 토이 스토리 | 제출 시각 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| (예시) 민수 | 1234 | S | A | B | 안 봄 | C | A | D | B | 2026-11-07 21:30 |

**필수 조건:** 비교 화면이 시트를 읽어 올 때 비밀번호 칸은 절대 함께 내보내지 않는다. 그렇지 않으면 누구나 다른 사람의 비밀번호를 볼 수 있다.

## 5. 완성 기준

아래 확인 목록을 모두 통과하면 완성으로 본다. 각 항목 아래에 확인 방법을 적었고, 통과한 항목은 체크한다.

### 기능

- [ ] 8편을 S\~D 다섯 줄로 끌어다 놓기와 누르고 고르기 두 방식 모두로 옮길 수 있다. 확인: 컴퓨터와 휴대폰에서 각각 두 방식으로 옮겨 본다.
- [ ] 이름과 4자리 비밀번호로 제출하면 시트에 한 줄이 생긴다. 확인: 제출 후 시트를 열어 본다.
- [ ] 같은 이름과 비밀번호로 다시 제출하면 줄이 새로 생기지 않고 덮어써진다. 확인: 등급을 바꿔 다시 제출하고 시트의 줄 수를 확인한다.
- [ ] 같은 이름에 틀린 비밀번호로는 제출할 수 없다. 확인: 틀린 비밀번호로 제출해 거절되는지 본다.
- [ ] 제출하기 전에는 비교 화면이 보이지 않는다. 확인: 처음 접속해서 확인한다.
- [ ] 대기칸에 남긴 영화는 "안 봄"으로 저장되고 평균에서 빠진다. 확인: 일부러 영화를 남기고 제출한 뒤, 평균을 직접 계산해 맞춰 본다.

### 비교 화면

- [ ] 영화별 평균 등급, 등급 분포, 본 사람 수가 표시된다. 확인: 시험용 결과를 넣고 직접 계산한 값과 맞춰 본다.
- [ ] 의견이 가장 갈린 영화가 맨 위에 강조된다. 확인: 일부러 S와 D가 섞인 영화를 만들어 본다.
- [ ] 나와 가장 비슷한 사람, 가장 다른 사람이 표시된다. 확인: 나와 똑같은 결과를 하나 넣어 가장 비슷한 사람으로 나오는지 본다.
- [ ] 이름으로 개인 결과를 찾아 펼쳐 볼 수 있다. 확인: 시험용 이름으로 검색해 본다.

### 규모와 안전

- [ ] 30\~40명분의 결과가 있어도 비교 화면이 휴대폰에서 읽기 쉽다. 확인: 시험용 결과 30\~40줄을 시트에 넣고 휴대폰으로 본다.
- [ ] 여러 명이 거의 동시에 제출해도 결과가 섞이거나 사라지지 않는다. 확인: 두세 대 기기로 동시에 제출해 본다. 단톡방에 링크를 올리면 실제로 한꺼번에 제출하는 일이 생긴다.
- [ ] 비교 화면이 받는 데이터에 비밀번호가 들어 있지 않다. 확인: 비교 화면이 받아 온 데이터를 직접 열어 확인한다.

### 화면과 배포

- [ ] 휴대폰과 컴퓨터, 밝은 화면과 어두운 화면 모두에서 잘 보인다. 확인: 각 환경에서 열어 본다.
- [ ] 친구가 가입 없이 링크만으로 열고 제출할 수 있다. 확인: 어떤 서비스에도 로그인하지 않은 기기로 열어 본다.
- [ ] 운영자가 따라 할 수 있는 시트 연결과 호스팅 설정 안내가 함께 있다. 확인: 안내만 보고 처음부터 설정해 본다.

### 확인 순서

1. 혼자서 기능과 비교 화면을 확인한다.
2. 시험용 결과 30\~40줄로 규모를 확인한다.
3. 친구 두세 명에게 먼저 링크를 보내 실제 사용을 확인한다.
4. 문제가 없으면 시험용 결과를 지우고 30명 전체에게 공유한다.

## 참고 사항

이 기획은 친구끼리 쓰는 용도를 전제로 하며, 아래 제약을 알고 운영한다.

- **보안 수준:** 제출 주소를 아는 사람은 누구나 결과를 보낼 수 있다. 링크는 친구들에게만 공유하고 공개된 곳에는 올리지 않는다.
- **비밀번호:** 시트에 그대로 저장되어 운영자가 볼 수 있다. 평소 쓰는 비밀번호를 쓰지 말라고 안내한다.
- **결과 숨기기:** "제출 전 비교 화면 숨기기"는 친구끼리 쓰기에 충분한 수준이며, 마음먹고 우회하는 것까지 막지는 않는다.
- **이번 범위에서 뺀 것:** 영화 추가·변경, 등급 이름 바꾸기, 포스터 이미지, 마감 후 일괄 공개, 시트의 변경 기록 보관.

### 다음 단계

이 기획안을 검토해 확정한 뒤, 실제 제작 여부와 일정을 따로 정한다. 제작할 때는 페이지 파일, 구글 시트 연결 코드, 운영자용 설정 안내를 함께 만든다.
